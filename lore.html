Core Features of LoreKeeper

The Central Wiki/Database

At its heart, LoreKeeper is a private wiki. Users create structured entries using customizable templates for Characters, Locations, Factions, Items, and more. The system's key innovation is bi-directional linking; linking a character to their birthplace automatically creates a backlink on the location's page, weaving a self-organizing web of lore.

The Interactive Timeline

This premium feature allows creators to visualize their world's history. Users can place events on a dynamic timeline, track character lifespans, and see how different narrative arcs overlap. This transforms a list of dates into a coherent, visual story, making it easy to spot inconsistencies and understand causality.

The Relationship Map

To untangle the complex web of character connections, the Relationship Map auto-generates a visual node-based graph. By linking characters with labels like "ally," "rival," or "family," the system produces an interactive chart that makes political intrigue and family trees instantly understandable.

The Atlas

This feature gives geographical context to the world. Creators can upload their own maps and drop interactive pins on locations. Each pin links directly to its corresponding wiki entry, turning a static image into an explorable, layered world. For game masters, it includes a "fog of war" feature to reveal locations to players as they discover them.

The Mobile Companion

Recognizing that inspiration strikes anywhere, LoreKeeper offers a streamlined mobile experience. It is not a shrunken version of the desktop app but a purpose-built "field journal" optimized for two key tasks: quick capture of new ideas and quick reference to existing information. All data is synced and available offline.

Technical Architecture

To deliver a modern, robust, and scalable experience, LoreKeeper is built on a professional-grade technology stack organized within a monorepo.

  • Backend: A modular, object-oriented API built with NestJS (a Node.js framework) and TypeScript. Each feature (authentication, projects, entries) is a self-contained module, ensuring the codebase is clean, maintainable, and scalable.
  • Frontend: A fast and interactive user interface built with Next.js (a React framework) and TypeScript. It utilizes a component-based architecture for building complex UIs like the timeline and relationship map.
  • Database: A PostgreSQL database serves as the primary data store. Its relational nature is a perfect fit for the interconnected data of a fictional world. The backend interacts with it via the Prisma ORM for type-safe database access.

Vision and Monetization

LoreKeeper will operate on a freemium model. The core wiki functionality will be free to allow users to begin building their worlds and experience the platform's value. The more advanced visualization tools—The Timeline, The Relationship Map, and The Atlas—along with professional features like real-time collaboration, will be part of a premium subscription.
