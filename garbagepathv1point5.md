Garbage Path - Alpha v1.5 Archive
This archive contains the complete source code for the Alpha v1.5 release of Garbage Path, as of September 6, 2025.

This version is considered a feature-complete Minimum Viable Product (MVP), ready for initial testing with a small group of users.

Core Features in this Version:
Dual User Modes: Full functionality for both logged-in users (cloud-saved data) and guests (local browser storage).

User Authentication: Secure sign-up, login, and account deletion using Firebase Authentication.

Profile Management: Users can create and edit a public profile with a username, bio, location, and a personal support link.

Core Map Functionality:

GPS location tracking with a moving user icon.

Photo pinning with image uploads to Firebase Storage.

"Find Me" functionality to re-center the map.

Session Management:

Multi-session saving and loading for both guests and logged-in users.

Ability to delete private sessions.

Community Features:

Users can "publish" completed routes to a public community map.

A toggle to view all community-submitted routes and pins.

Clickable usernames on community pins to view the creator's public profile.

Ability to manage and delete your own public contributions.

Legal & Onboarding:

A mandatory Terms of Service agreement on first use, including an 18+ age requirement.

An "Info" modal explaining the app's mission and functionality.
