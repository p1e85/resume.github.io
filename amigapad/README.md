# Amiga Pad

A retro-styled multi-tab notepad inspired by **Amiga Workbench 1.3** and Windows Notepad.

Built with pure HTML, CSS, and JavaScript — no frameworks.

## Features
- Authentic Amiga Workbench 1.3 look & feel (light + dark theme)
- Multiple tabs with drag support
- Full Notepad-like File/Edit/Format/View menus
- Open/Save .txt files
- Save/Load full sessions (.amigapad)
- Auto-save every 30 seconds
- Keyboard shortcuts (Ctrl+N, Ctrl+S, Ctrl+O, F5, etc.)
- Draggable window in Workbench mode
- Responsive Classic mode for mobile

## How to Run
1. Open `index.html` in any modern browser (Chrome, Firefox, Edge recommended)
2. No installation needed — works offline once loaded

## Controls
- **File** → New, Open, Save, Save As, Sessions
- **View** → Toggle Theme + Switch between Workbench / Classic mode
- **Format** → Word Wrap
- Shortcuts: Ctrl+N (New), Ctrl+O (Open), Ctrl+S (Save), Ctrl+Shift+S (Save As), F5 (Time/Date)
